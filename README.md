# goit-algo-hw-04

This is a small project I worked on during my studies.

## What is he doing?

- **main.py** - A small console application. It can manage a contact list (add, edit, and display them).
- **total_alery.py** - A small module that can open a file containing a list of employee salaries in the appropriate format. It calculates the total salary and average salary.
- **cats_info.py** - A small module that opens a file containing cat information in the appropriate format at a specified path. It returns this information as a dictionary.
- **color_dir.py** - A small script for use in the console. It accepts a folder path and displays its contents in the console as a tree. Folders and files are now displayed in different colors for convenience.
